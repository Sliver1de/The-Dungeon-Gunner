# Unity Project README



## 🎮 地下城枪手

> **基于unity制作的2Droguelike类射击游戏**

## 📌 技术亮点

✅ **Unity 版本**：2022.3.43 LTS（或其他版本）  
✅ **编程语言**：C#  
✅ **UI 框架**：Unity UI / UGUI / TextMeshPro  
✅ **动画系统**：Animator / Timeline  
✅ **存档系统**：JSON / XML / PlayerPrefs / SQLite  
✅ **音效管理**： Unity Audio  
✅ **AI 行为**：FSM / AStar/ NavMesh
